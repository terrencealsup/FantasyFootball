# Fantasy Football Analytics

This repo contains code for pulling Fantasy Football (FF) data from various sources as well running analytics and simulations.

## Data Fetchers

Code for fetching data is contained within `data_fetchers/`

The raw data will be saved to `data/raw` and any processed data will be saved to `data/processed`.

Documentation for each data file pulled will be saved at `data/Documentation.md`.
